# Merge Authorization

- Check that the user's permission covers this PR and commit.
- Verify current GitHub evidence: the head matches, the PR is mergeable,
  required checks and repository gates pass, and reviewer feedback exists.
- Check the handoff against current comments: every eligible request has a
  supported posted reply.
- Return authorization or all reasons for refusal. State whether missing
  replies or handoff details are the only problem.
- Do not repeat the code review.
